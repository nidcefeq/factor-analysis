# Dermatology Factor Analysis and Dimensionality Reduction

## Описание проекта

Проект посвящен факторному анализу и снижению размерности медицинского датасета по дерматологическим заболеваниям.

Основная цель исследования — выявить скрытые факторы, объединяющие клинические и гистопатологические признаки, а также изучить структуру данных с использованием методов снижения размерности.

## Используемые технологии

* Python
* Pandas
* NumPy
* Scikit-learn
* Factor Analyzer
* Seaborn
* Matplotlib
* Plotly

## Датасет

Используется датасет по диагностике дерматологических заболеваний, включающий 6 классов болезней:

1. Psoriasis
2. Seborrheic Dermatitis
3. Lichen Planus
4. Pityriasis Rosea
5. Chronic Dermatitis
6. Pityriasis Rubra Pilaris

Данные содержат:

* клинические признаки;
* гистопатологические признаки;
* возраст пациента;
* диагностический класс заболевания.

## Этапы работы

### 1. Подготовка данных

* удаление неинформативных признаков;
* обработка пропусков;
* преобразование типов данных;
* стандартизация признаков.

### 2. Проверка применимости факторного анализа

Использованы:

* KMO Test
* Bartlett's Test of Sphericity

Результаты:

* KMO = 0.907
* Bartlett p-value < 0.05

Это подтверждает пригодность данных для факторного анализа.

### 3. Исследование структуры данных

Построены:

* корреляционная матрица;
* scree plot;
* графики объясненной дисперсии.

### 4. Методы снижения размерности

В работе применялись:

* Principal Component Analysis (PCA)
* Factor Analysis
* Linear Discriminant Analysis (LDA)
* Singular Value Decomposition (SVD)
* t-SNE

### 5. Визуализация

Построены:

* тепловые карты корреляций;
* графики собственных значений;
* визуализации факторов;
* 3D t-SNE проекция классов заболеваний.

## Результаты

PCA показал, что значительная часть информации может быть сохранена при использовании примерно **4–5 компонент**.

Факторный анализ выявил несколько интерпретируемых скрытых факторов.

## Интерпретация факторов

### Фактор 1 — Лихеноидный воспалительный паттерн

Характеризует выраженные иммунные и структурные изменения кожи.

Основные признаки:

* oral_mucosal_involvement
* polygonal_papules
* melanin_incontinence
* band_like_infiltrate
* saw_tooth_retes

### Фактор 2 — Псориатический паттерн

Связан с гиперпролиферацией эпидермиса.

Основные признаки:

* clubbing_rete_ridges
* elongation_rete_ridges
* munro_microabcess
* thinning_epidermis

### Фактор 3 — Фолликулярные изменения

Отражает нарушения процессов кератинизации вокруг волосяных фолликулов.

Основные признаки:

* follicular_papules
* follicular_horn_plug
* perifollicular_parakeratosis

### Фактор 4 — Поверхностные клинические проявления

Отражает внешние признаки воспаления кожи.

Основные признаки:

* erythema
* scaling

### Фактор 5 — Глубокие структурные изменения дермы

Связан с хроническими тканевыми изменениями.

Основные признаки:

* fibrosis
* acanthosis

## Основные выводы

Факторный анализ позволил выявить скрытые группы взаимосвязанных признаков, соответствующие различным патогенетическим механизмам дерматологических заболеваний.

Методы снижения размерности подтвердили наличие компактной структуры данных и позволили визуализировать различия между диагностическими классами.

Полученные результаты могут использоваться для:

* медицинской интерпретации признаков;
* исследования структуры заболеваний;
* построения диагностических моделей машинного обучения;
* уменьшения размерности данных перед обучением классификаторов.
